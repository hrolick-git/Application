# Список файлів

Початковий файл-дерево (див. README форма). Кожен файл у репозиторії + короткий опис.

- `package.json` – корінь монорепо пункти скриптів.
- `.env.example` – приклад змінних оточення.
- `docker-compose.yml` – запуск контейнерів.
- `.devcontainer/...` – налаштування Codespaces.
- `apps/backend/...` – код серверу.
- `apps/frontend/...` – код фронтенду.
- `docs/*` – документація (плани, ризики, тощо).
- `.github/PULL_REQUEST_TEMPLATE.md` – шаблон PR.
- `LICENSE`, `.gitignore` – загальноприйняті файли.

(Список може бути оновлено при додаванні файлів.)
