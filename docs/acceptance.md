# Критерії прийняття

1. **Аутентифікація**
   - Реєстрація/вхід працюють.
   - Пароль хешується.
   - JWT зберігається в локальному сховищі.
2. **Події**
   - Публічний список із кнопками Join/Leave.
   - Деталі події – всі поля, список учасників.
   - Організатор може редагувати/видаляти.
   - Створення нової події – валідація, збереження.
3. **Моя події**
   - Календар із місяць/тиждень.
   - Натискання веде до деталей.
4. **UI**
   - Адаптивний, Tailwind.
   - datetime-local для вибору дати/часу.
   - Календар без зовнішніх бібліотек.
5. **Документація**
   - Інструкції мінімальні.
6. **Тести**
   - Є тести прикладні (unit, integration, e2e).
7. **Docker**
   - `docker-compose up` піднімає усі служби.

Усі пункти повинні пройти на чистому середовищі.
