# Деплой

1. Підготувати `.env` з реальними змінними.
2. Запустити `docker-compose up --build` (локально/сервер).
3. Після старту викликати `npm run db:migrate` і `npm run db:seed` у контейнері backend.
4. (Необов’язково) використовувати CI для запуску тестів.
5. Production – той самий docker-compose, лише інші значення env.

> **Примітка:** зовнішній хостинг не вказано.
